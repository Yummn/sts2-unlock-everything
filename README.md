# 一键全解锁 / UnlockEverything

> 项目分类：个人项目 / 《杀戮尖塔 2》Mod / 存档解锁辅助 / 归档可用

用于快速解锁《杀戮尖塔 2》档案内容的辅助 Mod。这个仓库主要保存已发布版本与安装说明，安装包位于 GitHub Releases。

## 下载

推荐使用最新版本：

- [v0.1.2](https://github.com/Yummn/sts2-unlock-everything/releases/tag/v0.1.2)
- [全部 Releases](https://github.com/Yummn/sts2-unlock-everything/releases)

当前发布包覆盖：

- Android v0.103.x
- Android v0.110.1
- PC v0.107.x

请按 Release 文件名选择与当前游戏版本一致的安装包。

## 安装

1. 下载对应版本的 ZIP。
2. 解压后，将其中的 `UnlockEverything` 文件夹完整复制到游戏 `mods/` 目录。
3. 在启动器中启用模组。

## 维护状态

这是一个功能单一的辅助 Mod，旧版本主要用于兼容与留档；通常建议优先使用最新 Release。
