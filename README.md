# 一键全解锁（Unlock Everything）

这是一个《杀戮尖塔 2》档案辅助 MOD，用来解锁当前档案中的全部进阶等级、百科发现和时间线纪元。它适合换设备、重新建档或测试内容时使用；如果希望保留原版逐步解锁的过程，请不要启用。

当前版本为 [v0.1.2](https://github.com/Yummn/sts2-unlock-everything/releases/tag/v0.1.2)，不依赖 BaseLib，也不包含 PCK 资源。

## 使用前提醒

这个 MOD 会修改当前档案的解锁状态。建议先备份存档，并确认选中的是准备修改的档案。

## 安装

在 Releases 中下载与游戏版本相符的压缩包：

- `Mobile-v103-PC-v107`：Android v0.103.2 或 PC v0.107.x
- `Mobile-v110.1`：Android v0.110.1

解压后，把完整的 `UnlockEverything` 文件夹放进游戏的 `mods` 目录，并在启动器中启用。不同版本的 DLL 不要混用。

本仓库目前只保留安装说明，编译后的可安装包统一放在 [GitHub Releases](https://github.com/Yummn/sts2-unlock-everything/releases)。
